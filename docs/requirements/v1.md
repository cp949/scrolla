# 현재 제공 범위

## 제품

`@cp949/scrolla-react`는 native scrolling을 유지하는 React 18/19용 custom scrollbar component입니다. 하나의 native scroll container와 수직·수평 custom scrollbar를 제공합니다.

## 제공 기능

- 수직·수평 scrolling과 overflow 측정
- thumb 크기·위치 동기화
- pointer drag, track click, native wheel
- Arrow/Page/Home/End keyboard 조작
- scroll 시작과 debounce 기반 idle 상태
- auto-hide
- RTL logical coordinate 정규화
- nested scroll과 native scroll chaining
- `ResizeObserver` 자동 갱신과 `refresh()`
- `scrollTo()`, `scrollBy()`, `getState()` imperative API
- React 18/19 ref와 state callback
- SSR/hydration 초기 마크업 안정성
- focus, ARIA와 reduced-motion 표현
- 명시적 CSS import를 사용하는 SCSS 기반 기본 스타일

## 공개 package 조건

- package: `@cp949/scrolla-react`
- module format: ESM
- `react`와 `react-dom`은 peer dependency
- CSS는 `@cp949/scrolla-react/styles.css`를 명시적으로 import
- core는 public package나 public subpath로 제공하지 않음
- import 시점에 `window`나 `document`에 접근하지 않음

## 브라우저 범위

- 하한 목표: Chrome Desktop 75
- 실제 검증: Linux 컨테이너 Chrome 83과 최신 Chrome Desktop
- 다른 desktop Chromium: 공식 보장하지 않음
- 모바일 browser, WebView, Firefox, Safari: 공식 지원하지 않음

세부 제한과 검증 범위는 [브라우저 지원 문서](../../BROWSER-SUPPORT.md)를 따릅니다.

## 제공하지 않는 기능

- 기존 scrollbar library의 public API 동시 호환
- public core package
- React 외 adapter
- auto-height와 content-size translation
- mobile-native 전환
- 임의 renderer callback
- 모든 browser·OS 조합에 대한 지원 보장
- CommonJS `require` entry
